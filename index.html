Method

Three independent families of evidence.

Agreement between families is what makes a verdict credible — findings within one family are largely the same fact observed twice, and are damped accordingly.

Structural

Real chunk, segment and box walkers for PNG, JPEG, RIFF, ISO-BMFF, GIF, BMP and PDF — with CRC-32 validated on every PNG chunk. Catches payloads appended past an end-marker, data in free boxes and JUNK padding, private chunks, and header size-field mismatches. A candidate archive is opened and its directory walked before it's reported, so a chance byte match is never called a finding.

Spatial

RS analysis and Sample Pair Analysis both estimate the embedding rate, not merely its presence, and rest on different assumptions — so their agreement is real corroboration. Alongside them, the Westfeld–Pfitzmann χ² attack run block-wise to localise a payload, and bit-plane correlation that tells "noisy because it's a photo of gravel" from "noisy because it's ciphertext".

Transform (DCT)

This is where JPEG steganography actually lives. Once an image is decoded to pixels the traces are gone, so the tool ships its own baseline JPEG entropy decoder and reads quantised DCT coefficients straight from the scan — no libjpeg binding needed. Validated against libjpeg by IDCT round-trip in the test-suite.

How the number is reached

Every detector emits a base-10 log likelihood ratio — how much more probable that observation is if a payload is present than if the carrier is clean. Nothing else moves the score, so every point of it traces back to a named measurement you can inspect in the Findings tab. Ratios combine as posterior log-odds from a deliberately low prior (5%), because steganography is rare in absolute terms and a tool that starts from a coin-flip manufactures false positives.

  • Proof is not diluted. A clean LSB result says nothing about an appended archive — they answer different questions. Once one observation reaches the proof tier, exculpatory findings from other families stop being subtracted.
  • "Could not measure" is never reported as "clean". A detector that runs without reaching a conclusion floors the verdict at inconclusive, and the report names it.
Honest coverage

Where it's blind.

Knowing where a tool stops working is part of using it. These are stated up front rather than discovered in casework.

Whole-file LSB in noisy PCM audio Not detectable. Measured across clean and embedded pairs, the LSB transition rate is 0.500 either way — every recording has a noise floor, dither is applied deliberately, and lossy round-trips add reconstruction noise. The tool reports inconclusive rather than guessing. What it does catch reliably is data written into digital silence, which discriminates perfectly.
F5 / OutGuess via calibration Measured, but not scored. Crop-and-recompress calibration is implemented and reported, but the ratio moves with JPEG quality on clean images (0.62–1.16 across Q70–Q95). A fixed threshold labelled every Q70 JPEG as F5-embedded in testing, so no threshold ships.
Progressive JPEG Coefficient decoding is baseline-sequential only. Progressive files are detected and reported as a limitation rather than decoded incorrectly.
Adaptive schemes J-UNIWARD, HUGO and WOW minimise a distortion function and defeat every classical statistic here. Detecting them needs rich-model features and a trained classifier.
LSB matching (±1) Not addressed by RS, SPA or χ², which key on pair-of-values structure that ±1 embedding never creates.

No negative result proves absence. A short or well-encrypted payload can fall below the detection floor of every technique implemented here.

Command line

For corpora, pipelines and scripting.

The browser runs one file at a time. For a whole seizure, exit codes and JSON output, use the CLI — it's the same engine.
